DSA Practice – Java

A structured Data Structures and Algorithms (DSA) practice repository built using Java.
This project contains implementations and practice problems covering fundamental programming concepts, data structures, algorithms, recursion, searching, sorting, and problem-solving techniques.

📌 About the Project

This repository was created to strengthen Java programming and DSA fundamentals through hands-on implementation.

It contains 105 Java source files organized into different topic-based packages. Each program focuses on a specific concept, algorithm, pattern, or problem-solving technique.

▶️ How to Run
Prerequisites

Install:

Java Development Kit (JDK) 22
Eclipse IDE, IntelliJ IDEA, or VS Code with Java support

Verify Java installation:

java -version
Run Using Command Line

Navigate to the source directory:

cd src

Compile a program:

javac array/binarysearch.java

Run it:

java array.binarysearch

For another package:

javac recursion/quicksort.java
java recursion.quicksort
💡 Example

The Binary Search implementation searches for an element in a sorted array:

int[] arr = {11, 22, 33, 44, 55, 66, 77, 88, 99};

int value = scn.nextInt();

System.out.println(binarysearching(arr, value));

The program returns the index of the searched element or -1 if the element is not present.
